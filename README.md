# EAUT – bản phát hành app Android

Kênh cập nhật của app **EAUT Mobile** (app không chính thức cho cổng sinh viên `qldt.eaut.edu.vn`).

- Tải bản mới nhất: [Releases → Latest](../../releases/latest), file `EAUT-v<phiên bản>.apk`.
- App đã cài sẽ **tự báo khi có bản mới**, kèm nội dung đã sửa/thêm. Bấm **Cập nhật** là app tự tải và mở trình cài.
  Lần đầu Android hỏi "Cho phép cài từ nguồn này" – bật cho EAUT là được.

Repo này chỉ chứa các bản phát hành (APK + ghi chú thay đổi), không chứa mã nguồn.
